# Sophia Agent Design Context

Sophia Agent is a terminal-native tool for technical teams and individual
developers. Interfaces should be calm, dense, and easy to scan during focused
work sessions.

## Principles

- Considered over clever: every visual choice has a job.
- Warmth through subtlety: use restrained terra-cotta accents and generous
  spacing without gradients or decorative noise.
- Density with clarity: prioritize status, commands, and actionable results.
- Community voice: write like a capable colleague, not a marketing site.

## Palette

- Primary: terra cotta `#D77757`
- Accent: blue `#5769F7`
- Dark surfaces: warm near-black, never cold navy
- Semantic colors: green success, red error, amber warning

The terminal logo is the seven-line Sophia BlurVision ASCII mark defined in
`src/components/LogoV2/WelcomeV2.tsx`.
